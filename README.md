# FPGA-Based Microcontroller Design using Verilog HDL

## Overview
This project focuses on the design and simulation of a basic microcontroller architecture using Verilog HDL. The system was developed during an industrial internship at CSIR-CEERI to understand processor architecture, FSM-based control design, and FPGA-oriented digital system development.

## Objective
- Study microcontroller architecture
- Design a modular microcontroller using Verilog HDL
- Implement FSM-based control logic
- Perform functional simulation and verification
- Understand FPGA-based digital design methodology

## System Architecture
The microcontroller consists of:
- Program Counter (PC)
- Instruction Memory
- Instruction Register (IR)
- Instruction Decoder
- FSM-based Control Unit
- Register File
- Arithmetic Logic Unit (ALU)
- Data Memory
- GPIO Interface

## Features
- Modular Verilog HDL implementation
- FSM-based control unit
- Multi-cycle instruction execution
- Functional simulation and verification
- ALU and register file design

## Tools Used
- Xilinx ISE
- Verilog HDL

## Folder Structure
src/        -> Verilog source files  
tb/         -> Testbench files  
waveforms/  -> Simulation outputs  
rtl/        -> RTL schematics  
docs/       -> Internship report and documentation  

## Results
The microcontroller design was successfully simulated and verified using waveform analysis.

## Important Note
This project was designed and simulated using FPGA development methodology. Physical FPGA implementation was not completed.
